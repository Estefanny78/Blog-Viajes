 Blog de Viajes

Blog de viajes creado para compartir destinos turísticos, recomendaciones,
fotografías y experiencias de viaje.


## Características

- Página principal con destinos turísticos.
- Información general
- Fotografías y descripciones de lugares.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## Cómo ver el proyecto

1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto.
3. Haz doble clic en el archivo `index.html`.

También puedes abrirlo con Visual Studio Code y utilizar una extensión como
Live Server.
